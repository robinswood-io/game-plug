# Agents Claude Code - Game Plug

## 🎯 Agent Métier Principal

### game-master (Sonnet)
**Spécialisation :** Expert RPG digital Call of Cthulhu 7e - Game master AI
**Utiliser pour :**
- Logique game master (narration, storytelling, horreur lovecraftienne)
- Mécaniques Call of Cthulhu 7e (skill checks, combat, SAN system)
- Génération avatars DALL-E (personnages, scènes)
- WebSocket real-time (synchronisation partie)
- Dice mechanics (d100, opposed rolls, criticals)
- Gestion scénarios (actes, PNJs, indices, secrets)
- AI narratif (GPT-4/5, Claude prompts)

**Mots-clés déclencheurs :**
`Call of Cthulhu`, `CoC`, `RPG`, `game master`, `narration`, `WebSocket`, `DALL-E`, `dice`, `d100`, `SAN`, `scénario`, `PNJ`, `Lovecraft`

**Localisation agent :** `~/.claude/agents/game-master.md`
