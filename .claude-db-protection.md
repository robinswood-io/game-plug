# Protection Base de Données Game Plug

## ⛔ INTERDICTION ABSOLUE

**INTERDIT de wiper/réinitialiser la base de données `roleplug` sans backup préalable.**

Cette règle s'applique à TOUS les agents Claude Code et à TOUTES les opérations.

## Contexte

- **Date création règle :** 2026-01-04
- **Raison :** Perte de données session GM avec personnage Vlad Kowalski
- **Demande utilisateur :** "Je te l'interdit"

## Actions Interdites SANS Backup

❌ `docker-compose down -v` (supprime volumes)
❌ `DROP DATABASE roleplug`
❌ `TRUNCATE TABLE characters/game_sessions/users`
❌ `DELETE FROM` sans clause WHERE restrictive
❌ Recréation complète du schéma
❌ `docker volume rm game-plug-postgres-dev`

## Workflow OBLIGATOIRE Avant Toute Modification Destructive

1. **Créer backup complet**
   ```bash
   docker exec game-plug-db-dev pg_dump -U roleplug roleplug > /opt/workspace/game-plug/backups/backup-$(date +%Y%m%d-%H%M%S).sql
   ```

2. **Vérifier backup valide**
   ```bash
   wc -l /opt/workspace/game-plug/backups/backup-*.sql
   grep -c "COPY public" /opt/workspace/game-plug/backups/backup-*.sql
   ```

3. **Obtenir validation utilisateur EXPLICITE**

4. **Effectuer modification**

5. **Vérifier intégrité post-modification**

## Système de Backup Automatique

### Backup Quotidien (Cron)

```bash
# Ajouter au crontab de l'utilisateur ubuntu
0 3 * * * docker exec game-plug-db-dev pg_dump -U roleplug roleplug > /opt/workspace/game-plug/backups/daily-$(date +\%Y\%m\%d).sql 2>&1
```

### Backup Avant Déploiement

**Hook pré-déploiement :** Créer backup automatique avant tout déploiement/restart.

### Rétention

- Backups quotidiens : 30 jours
- Backups manuels : conservation illimitée

## Restauration

En cas de perte de données :

```bash
# Restaurer depuis backup le plus récent
cat /opt/workspace/game-plug/backups/backup-YYYYMMDD-HHMMSS.sql | docker exec -i game-plug-db-dev psql -U roleplug roleplug
```

## Violation de Règle

Si cette règle est violée :
1. Arrêt immédiat de l'opération
2. Tentative de restauration depuis dernier backup
3. Rapport détaillé à l'utilisateur
