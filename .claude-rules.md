## Critical Rules

### 1. Deployment Protocol

#### ❌ FORBIDDEN - Local deployment from project directory

```bash
# NEVER do this:
cd /srv/workspace/game-plug && docker compose up -d
```

Creates isolated network, bypasses Traefik routing, no external access.

#### ✅ REQUIRED - Central orchestration deployment

```bash
# ALWAYS use:
cd /srv/workspace && docker compose -f docker-compose.apps.yml up -d --build game-plug
```

Uses `traefik_public` + `dev_network`, proper routing, production-ready.

**Verification:**
```bash
docker network ls | grep -E 'traefik_public|dev_network'
docker ps | grep game-plug
docker compose -f docker-compose.apps.yml logs -f game-plug
```

### 5. WebSocket Real-time Rules

**Message Format (Typed):**

```typescript
interface WSMessage {
  type: 'join_session' | 'player_roll' | 'gm_roll' | 'effect_applied' | ...;
  data: TypedData;           // Match message type
  timestamp: Date;
}
```

**Broadcasting Rules:**

```typescript
// ✅ YES - Broadcast to specific session only
broadcastToSession(sessionId, message, excludeSocket);

// ❌ NO - Don't broadcast to all players globally
// (breaks session isolation)
```

**Message Types (Complete List):**

| Type | Direction | Data | Purpose |
|------|-----------|------|---------|
| `join_session` | Client→Server | `{sessionId, userId, role}` | Player joins |
| `player_roll` | Client→Server | `{rollType, result, characterId}` | Dice roll |
| `gm_roll` | Server→All | `{rollType, result}` | GM announcement |
| `effect_applied` | Server→All | `{characterId, effectType, value}` | Buff/debuff |
| `projection_update` | Server→All | `{imageUrl, description}` | GameBoard image |
| `narration` | Server→All | `{text, isPublic}` | GM narration |
| `ambiance` | Server→All | `{type, isActive}` | Mood/atmosphere |

### 13. Common Gotchas

**WebSocket Session Isolation:**

```typescript
// ✅ CORRECT - Only broadcast to target session
broadcastToSession(sessionId, message);

// ❌ WRONG - Leaks data across sessions
broadcastToAll(message);
```

**Image Persistence:**

```typescript
// ✅ CORRECT - Saves avatar permanently
const url = await generateCharacterAvatar(
  description,
  name,
  occupation,
  age,
  characterId  // Auto-downloads and saves
);

// ❌ WRONG - Only temporary OpenAI URL
const url = response.data[0].url;  // Expires in 1 hour
```

**TypeScript Module Resolution:**

```typescript
// ✅ CORRECT - Use path aliases
import { User } from '@shared/schema';
import { useCharacters } from '@/hooks/use-characters';

// ❌ WRONG - Relative imports across modules
import { User } from '../../../shared/schema';
```

**Docker Networking:**

```bash
# ✅ Health check works
docker exec game-plug-app curl http://localhost:5000/api/health

# ❌ DNS resolution fails (wrong network)
docker exec game-plug-app curl http://postgres:5432
```

## Emergency Procedures

### Production Issue: Container Won't Start

```bash
# 1. Check logs
docker compose -f docker-compose.apps.yml logs game-plug

# 2. Check environment
docker compose -f docker-compose.apps.yml config | grep OPENAI_API_KEY

# 3. Verify networks
docker network inspect traefik_public | grep game-plug

# 4. Restart
docker compose -f docker-compose.apps.yml restart game-plug

# 5. Verify health
docker ps | grep game-plug
```

### Database Connection Error

```bash
# 1. Check connection string
echo $DATABASE_URL

# 2. Test direct connection
docker exec game-plug-app npm run check

# 3. Push schema
docker exec game-plug-app npm run db:push

# 4. Check PostgreSQL health
docker compose -f docker-compose.apps.yml logs postgres
```

### WebSocket Not Connecting

```bash
# 1. Verify server is running
curl -v http://localhost:5002/api/health

# 2. Check WebSocket path
# Browser DevTools → Network → WS tab
# Should connect to ws://game-plug.rbw.ovh/game-ws

# 3. Check CORS (if applicable)
# Look for WebSocket upgrade headers in request

# 4. Restart server
docker compose -f docker-compose.apps.yml restart game-plug
```
