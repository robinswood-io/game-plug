MIGRATION PATTERNS REFERENCE
════════════════════════════════════════════════════════════════════════════

Jest → Vitest Mapping:

  jest.fn()              → vi.fn()
  jest.spyOn()           → vi.spyOn()
  jest.mock()            → vi.mock()
  jest.clearAllMocks()   → vi.clearAllMocks()
  jest.resetAllMocks()   → vi.resetAllMocks()

  @jest/globals          → vitest
  describe/it/expect     → No import needed (globals: true)


NestJS Testing (Unchanged):

  Test.createTestingModule()  ← Still works
  module.get(Service)         ← Still works
  @nestjs/testing             ← Still works


HTTP Mocking (MSW):

  Before: nock or supertest
  After:  addMockHandler(http.get(...))

  import { addMockHandler } from '../test/setup'
  import { http, HttpResponse } from 'msw'
  
  addMockHandler(
    http.get('https://api.example.com/data', () => {
      return HttpResponse.json({ result: 'success' })
    })
  )

TROUBLESHOOTING QUICK REFERENCE
════════════════════════════════════════════════════════════════════════════

"Cannot find module 'vitest'"
  → npm install --save-dev vitest@^4.0.0

"Decorators not recognized"
  → unplugin-swc handles this (installed in package.json)

"Tests timeout"
  → Increase testTimeout in vitest.config.ts

"MSW not intercepting"
  → Verify test/setup.ts exists and is in setupFiles

"Path aliases not working"
  → Check vitest.config.ts has your aliases

"Type errors with vi.fn()"
  → Import from 'vitest' not '@jest/globals'
