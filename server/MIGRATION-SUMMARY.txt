PACKAGE.JSON SCRIPTS
────────────────────

Before (Jest):
  "test": "jest"
  "test:watch": "jest --watch"
  "test:cov": "jest --coverage"
  "test:e2e": "jest --config ./test/jest-e2e.json"

After (Vitest):
  "test": "vitest run"
  "test:watch": "vitest"
  "test:cov": "vitest run --coverage"
  "test:e2e": "vitest run --config vitest.config.ts"


QUICK START
───────────

1. Install dependencies:
   $ cd /srv/workspace/game-plug/server
   $ npm install

2. Verify setup:
   $ npm run test                    # (if tests exist)
   $ npm run test:cov               # Generate coverage

3. Migrate existing tests:
   - Open each .spec.ts file
   - Replace jest imports with vitest
   - Replace jest.fn() with vi.fn()
   - Follow patterns in test/MIGRATION-TEMPLATE.ts

4. Run tests:
   $ npm run test:watch              # Interactive mode
   $ npm run test -- --grep "Filter" # Specific tests

TROUBLESHOOTING
───────────────

Problem: "Cannot find module 'vitest'"
Solution: npm install --save-dev vitest@^4.0.0

Problem: "Decorators not recognized"
Solution: unplugin-swc in vitest.config.ts handles this

Problem: "Tests timeout"
Solution: Increase testTimeout in vitest.config.ts

Problem: "MSW not intercepting"
Solution: Check test/setup.ts is in setupFiles
