# Game-Plug Stack Documentation

## Project Overview

**Game-Plug** (aussi connu comme Rôle Plug) est une **plateforme RPG digitale complète pour Call of Cthulhu 7ème Édition**. Elle offre un écosystème intégré permettant aux maîtres de jeu et joueurs de dérouler des sessions immersives avec synchronisation temps réel, génération d'images IA, et interface thématique lovecraftienne.

**Type de Projet:** Full-stack web application (monorepo)
**Statut:** ✅ Migration Complete - Enterprise Stack Live
**URL Production:** https://game-plug.rbw.ovh

## Stack Technique

### Frontend ✅ Active

- **Framework:** Next.js 16 + React 19 + TypeScript
- **Build Tool:** Turbopack (integrated in Next.js)
- **Routing:** App Router (file-based, server/client)
- **State Management:** TanStack Query v5 (server state)
- **UI Framework:**
  - Radix UI (composants unstyled)
  - shadcn/ui (composants applicatifs)
  - Tailwind CSS 3.4 + Custom Lovecraft Theme
- **Forms:** React Hook Form + Zod v4 validation
- **Animations:** Framer Motion 11
- **Authentication:** NextAuth.js v5 + JWT
- **Build Entry Point:** `apps/frontend/app/`

### Backend ✅ Active

- **Runtime:** Node.js 24
- **Framework:** NestJS 11 + TypeScript 5.7+ (strict mode)
- **Language:** TypeScript (strict mode enforced)
- **API Pattern:** REST endpoints with decorators
- **Entry Point:** `apps/backend/src/main.ts`
- **Modules:** 15 specialized modules (auth, characters, sessions, gameboard, dice, ai, inventory, effects, sanity, narrative, chapter-events, websockets, etc.)

### Real-time Communication

- **Protocol:** WebSocket (ws library 8.18)
- **Server Path:** `/game-ws`
- **Features:**
  - Session-based broadcasting (par sessionId)
  - Heartbeat/ping-pong pour maintenir les connexions
  - Typed message handling (RollData, EffectData, ProjectionData, etc.)
  - Support client/server disconnection recovery

**Message Types Supported:**
- `join_session` - Joueur rejoint une session
- `leave_session` - Joueur quitte
- `gm_roll` - Jet de dés du MJ
- `player_roll` - Jet de dés du joueur
- `ambiance` - Gestion d'ambiance
- `narration` - Texte narratif
- `effect_applied` - Effets appliqués
- `projection_update` - Mise à jour du GameBoard

### Database

- **DBMS:** PostgreSQL 16
- **ORM:** Drizzle ORM 0.39
- **Schema:** `shared/schema.ts` (single source of truth)
- **Migrations:** Drizzle Kit (`npm run db:push`)
- **Connection:** TCP via DATABASE_URL

**Key Tables:**
- `users` - Accounts utilisateurs
- `characters` - Personnages CoC7e
- `sessions` - Sessions de jeu (GM)
- `gameboards` - Projections d'images
- `inventory` - Objets et équipement
- `effects` - Effets appliqués

### AI Integration (OpenAI)

**Modèles:**
- **DALL-E 3** - Génération d'images (avatars + scènes GameBoard)
- **GPT-4o** - Assistance narrative et descriptions thématiques

**Features Implemented:**

1. **Avatar Generation** (`server/openai.ts`)
   ```typescript
   generateCharacterAvatar(description, characterName, occupation?, age?)
   ```
   - 1920s portrait style (sepia/B&W)
   - Lovecraftian atmosphere
   - Saved locally in `/public/avatars/{characterId}/`

2. **Scene Generation** (GameBoard Projection)
   ```typescript
   generateSceneImage(prompt: string)
   ```
   - Aspect ratio: 1792x1024 (projection-optimized)
   - Quality: HD (high-quality)
   - Style: Dark atmospheric 1920s horror painting

3. **Narrative Assistance**
   - Phobia descriptions (GPT-4o)
   - Mania descriptions (GPT-4o)
   - Campaign suggestions
   - NPC dialogue

**Image Storage:**
- Temporary URLs: Direct OpenAI CDN links
- Persistent Storage: Downloaded to `/public/avatars/{characterId}/`
- Fallback: Local file serving via Express static middleware

### Build System

- **Frontend Build:** Vite compilation to `/dist/`
- **Backend Build:** esbuild (ESM format, bundled, `--platform=node`)
- **Output:** `/dist/index.js` (production entry point)
- **Package Manager:** npm 10+ or Bun 1.3.6

## Integration Points

### WebSocket Real-time Flow

```
Client connects → join_session message → Server adds to session group
                                        ↓
                            Message broadcast to all clients in session
                                        ↓
                         Effect propagated (dice roll, character update, etc.)
                                        ↓
                      All clients sync immediately (< 100ms latency)
```

### AI Generation Pipeline

```
Request avatar generation
    ↓
OpenAI DALL-E 3 API call (prompt engineering)
    ↓
Receive temporary URL from OpenAI
    ↓
Download image to `/public/avatars/{characterId}/`
    ↓
Store permanent local URL in database
    ↓
Return URL to client
```
